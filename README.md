# ArchitectZero — Venkata.Info

Personal portfolio website for **Venkata Sundaragiri** (aka *ArchitectZero*) — Senior SAP CX Suite Architect & Practice Leader.

## 🌐 Live Site

[venkata.info](https://venkata.info)

## 📋 Overview

This is a static, single-page portfolio website showcasing:

- **Hero** – Introduction and professional tagline
- **About** – Biography, career highlights, and key stats
- **Expertise** – SAP CX Suite, S/4HANA, AI & Joule, Cloud Architecture, and more
- **Services** – Consulting, solution design, SAP implementation, mentoring, and rapid experimentation
- **Certifications** – SAP certifications and academic credentials
- **Contact** – Contact form and direct contact details

## 🛠 Tech Stack

- Plain **HTML5**, **CSS3**, and vanilla **JavaScript** — no build tools required
- [Inter](https://fonts.google.com/specimen/Inter) + [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) from Google Fonts
- Fully **responsive** (mobile-first approach)
- **Dark theme** with animated background shapes and scroll-driven fade-ins

## 🚀 Getting Started

Simply open `index.html` in any modern browser — no server required.

```bash
git clone https://github.com/sundaragiriv/architectZero.git
cd architectZero
open index.html   # macOS
# or: start index.html  (Windows)
# or: xdg-open index.html  (Linux)
```
